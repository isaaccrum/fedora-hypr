# Hypratomic user configuration staging area

These files are copied by `hypratomic-bootstrap` into `~/.config/hypratomic/`.
They are deliberately *not* activated automatically.

Phase 1 goal: keep the Wayblue Hyprland session fully functional while proving
that our custom Atomic image builds, boots, updates, and rolls back correctly.

Phase 2 will add a version-controlled Hyprland configuration here and an
explicit activation command. Phase 3/4 will add the Omarchy-inspired theme and
Quickshell shell.
